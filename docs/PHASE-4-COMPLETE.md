## Key result

Phase 4 adds a new kind of object to the atlas:

**the QUESTION NODE.**

Some questions are scientifically serious before they have a known physical carrier.

A question node can later mature through:

```
question
→ operational definition
→ model
→ predicted coupling
→ observable
→ experiment
→ replicated evidence
→ physical atlas entry
```

This lets the project preserve questions such as the soul, survival after death, and nonlocal memory without pretending that a frequency or field has already been discovered.

## Most important boundary

The project will be **open to extraordinary hypotheses but strict about category**.

- A report is not automatically a mechanism.
- A correlation is not automatically a cause.
- A mathematical pattern is not automatically a physical law.
- A quantum effect somewhere in biology is not automatically a quantum theory of consciousness.
- A real vacuum fluctuation is not automatically extractable free energy.
- An unexplained experience is not automatically evidence of postmortem survival.
- Lack of a current mechanism is not proof that a hypothesis is false.

The purpose of the atlas is to make these distinctions visible.
